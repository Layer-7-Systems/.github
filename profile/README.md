# Layer 7 Systems

Internal engineering org. This repo hosts the org profile, architecture docs, and cross-cutting RFCs that do not belong to any single product repo.

## Where things live

- `profile/README.md` — this page, the org landing card.
- `docs/architecture/` — cross-cutting design docs and RFCs that span multiple repos.
- `docs/process/` — release, review, and ops process notes that apply to the whole org.

## Product repos

- [`autotask-mcp-retell`](https://github.com/Layer-7-Systems/autotask-mcp-retell) — Service Desk voice agent (Retell + MCP + Autotask).

## Conventions

- Issues that affect a single repo live in that repo.
- Issues that span repos, set policy, or define shared infrastructure live here.
- Architecture docs are markdown in `docs/architecture/`. One file per topic. Link from issues.
